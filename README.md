🚀 Getting Started

Welcome! Follow the simple steps below to install and run this project successfully on your local machine.

📦 Installation & Setup

Step 1: Install Dependencies

First, open your terminal in the project directory and run the following command:

npm install

This command will install all the required dependencies and packages.

Step 2: Run the Project

Once the installation is complete, execute:

npm run

This will start the project using the available npm scripts.

🎉 You're All Set!

That's it! Follow these two simple steps, and your project will be ready to run.

Note: Make sure you have "Node.js" (https://nodejs.org/) and npm installed on your system before getting started.
